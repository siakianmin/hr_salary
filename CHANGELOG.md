# Changelog

All notable changes to HR Salary are recorded here.

The project follows Semantic Versioning (`MAJOR.MINOR.PATCH`).

## [0.1.0] - 2026-08-16

### Added
- Initial standardized Python repository structure.
- Mandatory `docs/` documentation area.
- Mandatory version tracking through `VERSION`, `CHANGELOG.md`, and `src/hr_salary/version.py`.
- Separated source modules for UI, services, models, database, reports, utilities, and resources.
- Separated unit, integration, and regression test areas.
- Dedicated scripts, installer, and data directories.
