# HR Salary v0.1.0

**Date:** 16 August 2026

## Purpose
Initial repository foundation for the HR Salary application.

## Added
- Standard `src/hr_salary/` Python package layout.
- Separate UI, services, models, database, reports, utilities, and resources modules.
- Unit, integration, and regression test areas.
- Mandatory `docs/` documentation hierarchy.
- Mandatory semantic version control using `VERSION`, `CHANGELOG.md`, and `src/hr_salary/version.py`.
- Scripts, installer, and protected data directories.
- `.github/workflows/` reserved without any runnable workflow.

## Application functionality
No salary-calculation business functionality is released in this foundation version. Functional development begins from this controlled baseline.
