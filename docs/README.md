# HR Salary Documentation

This folder is mandatory for the HR Salary project and must remain part of the repository for the full project lifecycle.

## Documentation categories

- `development_rules.md` — mandatory repository and development rules.
- `architecture.md` — software architecture and module responsibilities.
- `user_manual/` — end-user instructions and operating procedures.
- `technical/` — technical specifications, database notes, interfaces, and maintenance information.
- `release_notes/` — version-by-version release documentation.

Documentation must be updated whenever a change affects application behavior, setup, database structure, user workflow, or release/version information.
